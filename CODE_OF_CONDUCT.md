# Code of Conduct

MyRide contributors are expected to keep project spaces respectful, constructive, and welcoming.

## Expected Behavior

- Discuss ideas and code without personal attacks.
- Give actionable feedback and assume good intent.
- Respect privacy and never publish another person's location or health information.
- Credit the work and sources of others.
- Accept maintainers' decisions about scope, safety, and project direction.

## Unacceptable Behavior

Harassment, discrimination, threats, doxxing, deliberate disruption, and publication of private information are not tolerated.

Project maintainers may edit or remove contributions and restrict participation when this policy is violated. Report conduct concerns privately through the repository owner's GitHub profile.
